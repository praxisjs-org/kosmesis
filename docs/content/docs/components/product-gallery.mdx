## About

Purely presentational — no Morphos equivalent. The thumbnail strip only renders when there's more
than one image.

## Usage

```tsx
import { ProductGallery } from "@/components/ui/product-gallery";

<ProductGallery images={["/front.jpg", "/back.jpg", "/detail.jpg"]} alt="Product photo" />
```
