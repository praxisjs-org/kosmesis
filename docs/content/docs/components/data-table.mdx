## Usage

```tsx
import { DataTable, DataTablePagination, DataTableState } from "@/components/ui/data-table";

interface Payment {
  id: string;
  amount: number;
  status: "pending" | "success" | "failed";
}

@Component()
class PaymentsTable extends StatefulComponent {
  @State() table = new DataTableState<Payment>({
    data: PAYMENTS,
    pageSize: 10,
    columns: [
      { key: "id", header: "ID", sortable: true },
      { key: "status", header: "Status", sortable: true },
      { key: "amount", header: "Amount", align: "right", sortable: true, cell: (row) => `$${row.amount.toFixed(2)}` },
    ],
  });

  render() {
    return (
      <div>
        <DataTable state={this.table} getRowKey={(row) => row.id} />
        <DataTablePagination state={this.table} />
      </div>
    );
  }
}
```

<Callout type="info">
  No `@tanstack/table`-style dependency — `DataTableState` computes sorted + paginated rows on
  read from plain arrays and indices. It covers the common 80% (sort a column, page through
  rows); bring your own filtering/row-selection state the same way if you need it.
</Callout>

## Props

### DataTableColumn

A config object, not a component — passed in `DataTableState`'s `columns` array.

| Prop | Type | Default |
|---|---|---|
| `key` | `string` | — required |
| `header` | `string` | — required |
| `sortable` | `boolean` | — |
| `align` | `"left" \| "right" \| "center"` | — |
| `cell` | `(row: T) => Children` | — |
| `sortValue` | `(row: T) => string \| number` | — |

### DataTableState

Instantiate directly (`@State() table = new DataTableState<T>({...})`).

| Prop | Type | Default |
|---|---|---|
| `data` | `T[]` | `[]` |
| `columns` | `Array<DataTableColumn<T>>` | `[]` |
| `pageSize` | `number` | `10` |

### DataTable

| Prop | Type | Default |
|---|---|---|
| `state` | `DataTableState<T>` | — required |
| `getRowKey` | `(row: T) => string` | — required |
| `class` | `string` | — |

### DataTablePagination

| Prop | Type | Default |
|---|---|---|
| `state` | `DataTableState<T>` | — required |
| `class` | `string` | — |
