## Usage

```tsx
import { HoverCard, HoverCardContent, HoverCardTrigger } from "@/components/ui/hover-card";

@Component()
class UserMention extends StatefulComponent {
  @State() card = new HoverCard();

  render() {
    return (
      <>
        <HoverCardTrigger card={this.card} class="font-medium underline">@praxisjs</HoverCardTrigger>
        <HoverCardContent card={this.card}>
          <p class="font-semibold">PraxisJS</p>
          <p class="text-sm text-muted-foreground">Signal-driven frontend framework.</p>
        </HoverCardContent>
      </>
    );
  }
}
```

`HoverCard`/`HoverCardTrigger` are Morphos's `PreviewCard`/`PreviewCardTrigger`, re-exported and
renamed.

## Props

### HoverCard

Re-exported directly from `@morphos/overlays` (as `PreviewCard`) — instantiate it in state
(`@State() card = new HoverCard()`) and pass it to `HoverCardTrigger`/`HoverCardContent`.

| Prop | Type | Default |
|---|---|---|
| `open` | `boolean` | — controlled open state |
| `defaultOpen` | `boolean` | — |
| `onOpenChange` | `(open: boolean) => void` | — |
| `openDelay` | `number` | — |
| `closeDelay` | `number` | — |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` |
| `align` | `"start" \| "center" \| "end"` | `"start"` |
| `sideOffset` | `number` | `4` |

### HoverCardTrigger

| Prop | Type | Default |
|---|---|---|
| `card` | `HoverCard` | — required |

### HoverCardContent

| Prop | Type | Default |
|---|---|---|
| `card` | `HoverCard` | — required |
