## About

Purely presentational — no Morphos equivalent, and deliberately avoids a heavy dependency like
`libphonenumber-js`: no format validation, just a dial-code `<select>` next to a plain `tel`
input, composed into one `{ country, dialCode, nationalNumber, value }` object on every change.
The bundled `DEFAULT_PHONE_COUNTRIES` list is small and non-exhaustive — pass your own `countries`
for full coverage.

## Usage

```tsx
import { PhoneInput } from "@/components/ui/phone-input";

<PhoneInput defaultCountry="BR" onChange={(value) => console.log(value.value)} />
```

## Props

| Prop | Type | Default |
|---|---|---|
| `defaultCountry` | `string` | `"US"` |
| `defaultValue` | `string` | `""` |
| `countries` | `PhoneCountry[]` | `DEFAULT_PHONE_COUNTRIES` |
| `disabled` | `boolean` | `false` |
| `placeholder` | `string` | `"Phone number"` |
| `onChange` | `(value: PhoneValue) => void` | — |
| `class` | `string` | — |
