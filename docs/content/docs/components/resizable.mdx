## Usage

```tsx
import { ResizableHandle, ResizablePanel, ResizablePanelGroup } from "@/components/ui/resizable";

<ResizablePanelGroup direction="horizontal" class="h-64 rounded-lg border">
  <ResizablePanel defaultSize={50}>
    <div class="flex h-full items-center justify-center p-6">One</div>
  </ResizablePanel>
  <ResizableHandle withHandle />
  <ResizablePanel defaultSize={50}>
    <div class="flex h-full items-center justify-center p-6">Two</div>
  </ResizablePanel>
</ResizablePanelGroup>
```

`ResizableHandle` needs no instance reference — it finds its two neighboring panels via
`previousElementSibling`/`nextElementSibling` and its direction via the closest
`[data-slot=resizable-panel-group]` ancestor, entirely through the DOM at drag time. Place it
directly between the two `ResizablePanel`s it should resize.

## Props

### ResizablePanelGroup

| Prop | Type | Default |
|---|---|---|
| `direction` | `"horizontal" \| "vertical"` | `"horizontal"` |

### ResizablePanel

| Prop | Type | Default |
|---|---|---|
| `defaultSize` | `number` | `50` — percentage of the group's main axis |

### ResizableHandle

| Prop | Type | Default |
|---|---|---|
| `withHandle` | `boolean` | `false` — renders a small grip glyph |
