## Usage

These components are presentation for the file upload composables in
[`@praxisjs/composables`](https://praxisjs.org/docs/composables/upload) (installed automatically by the
CLI). The composable is attached with `@Compose` in **your** component, so validation options (`accept`,
`maxSize`, `maxFiles`, …) stay yours, and is passed to the Kosmesis component as a prop.

```tsx
import { FileSelection } from "@praxisjs/composables";
import { FileInput, FilePicker } from "@/components/ui/file-picker";

@Component()
class Form extends StatefulComponent {
  @Compose(FileSelection, { accept: ".pdf", maxSize: 2 * 1024 * 1024 })
  selection!: FileSelection;

  render() {
    return (
      <>
        <FilePicker selection={this.selection} label="Choose file" />
        <FileInput selection={this.selection} />
      </>
    );
  }
}
```

`FileInput` looks like a text input and shows the chosen file name (or a count) in place of its
placeholder. Pair either with [File List](/docs/components/file-list) to show and remove the selection.

## Props

### FilePicker

| Prop | Type | Default |
|---|---|---|
| `selection` | `FileSelection` | — required |
| `label` | `string` | `"Choose file"` |
| `variant` / `size` | `Button` variant / size | `"outline"` / — |
| `disabled` | `boolean` | — |
| `class` | `string` | — |

### FileInput

| Prop | Type | Default |
|---|---|---|
| `selection` | `FileSelection` | — required |
| `placeholder` | `string` | `"No file chosen"` |
| `buttonLabel` | `string` | `"Browse"` |
| `disabled` | `boolean` | — |
| `class` | `string` | — |
