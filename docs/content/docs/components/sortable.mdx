## About

Purely presentational — no Morphos equivalent. Reordering is done the same way `Resizable`
handles dragging: walking and mutating the live DOM directly (`insertBefore`) rather than tracking
an items array in state, so each `SortableItem` stays fully consumer-owned (identified only by its
own `value`). Distinct from `Drag Items`, which repositions elements freely instead of reordering
a rank.

## Usage

```tsx
import { Sortable, SortableHandle, SortableItem } from "@/components/ui/sortable";

<Sortable onReorder={(order) => console.log(order)}>
  {items.map((item) => (
    <SortableItem key={item} value={item}>
      <SortableHandle />
      {item}
    </SortableItem>
  ))}
</Sortable>
```

## Props

### Sortable

| Prop | Type | Default |
|---|---|---|
| `onReorder` | `(order: string[]) => void` | — |
| `class` | `string` | — |

### SortableItem

| Prop | Type | Default |
|---|---|---|
| `value` | `string` | — |
| `class` | `string` | — |

`SortableHandle` accepts `class` only — a drag only starts from a `SortableHandle` inside the item, not from anywhere on the item itself.
