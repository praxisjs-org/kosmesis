## About

Purely presentational — no Morphos equivalent. Runs its own `requestAnimationFrame` loop rather
than reactive state: every particle fades independently every frame, which would mean a state
write (and a re-render) per particle per frame if it went through `@State`. Fills its parent by
default (`size-full` / `width: 100%; height: 100%`) — size it via a wrapping container or `class`.

## Usage

```tsx
import { MouseTrail } from "@/components/ui/mouse-trail";

<MouseTrail class="h-64 w-full" color="oklch(0.6 0.2 280)">
  <div class="flex h-full items-center justify-center">Hover me</div>
</MouseTrail>
```

## Props

| Prop | Type | Default |
|---|---|---|
| `color` | `string` | `"oklch(0.7 0.15 250)"` |
| `size` | `number` (max particle radius, px) | `6` |
| `length` | `number` (max trail particles) | `20` |
| `class` | `string` | — |
