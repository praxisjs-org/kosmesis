## About

Purely presentational — no Morphos equivalent. The hostname is derived from `url` via the `URL`
constructor (falling back to the raw string if it isn't fully-qualified). `image` is optional —
without it, the card is just title/description/hostname.

## Usage

```tsx
import { WebPreview } from "@/components/ui/web-preview";

<WebPreview
  url="https://example.com/docs"
  title="Example Docs"
  description="Everything you need to get started."
/>
```
