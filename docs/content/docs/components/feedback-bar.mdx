## About

Purely presentational — no Morphos equivalent. `value` behaves like `CalendarState.selected`:
pass a plain value for uncontrolled use, or a getter function to stay controlled. Clicking the
already-selected button clears it.

## Usage

```tsx
import { FeedbackBar } from "@/components/ui/feedback-bar";

<FeedbackBar onChange={(value) => console.log(value)} />
```

## Props

| Prop | Type | Default |
|---|---|---|
| `value` | `"up" \| "down" \| undefined` | — (uncontrolled when omitted) |
| `onChange` | `(value: "up" \| "down" \| undefined) => void` | — |
| `class` | `string` | — |
