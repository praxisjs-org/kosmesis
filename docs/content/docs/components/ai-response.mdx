## About

Purely presentational — no Morphos equivalent. `children` are already-rendered elements
(headings, lists, code, ...), not a raw markdown string, so this deliberately avoids a
markdown-parser dependency: it just styles whichever of those tags shows up via descendant
selectors, no `@tailwindcss/typography` plugin required.

## Usage

```tsx
import { AiResponse } from "@/components/ui/ai-response";

<AiResponse>
  <h2>Refund policy</h2>
  <p>Purchases made within the last <strong>30 days</strong> are eligible for a full refund.</p>
</AiResponse>
```

## Props

`AiResponse` accepts `class` and `children` only.
