## About

Purely presentational — no Morphos equivalent. Pointer-drag math the same shape as
`ResizableHandle`'s, translating the element instead of resizing a neighbor. Distinct from
`Sortable`, which reorders a rank instead of repositioning elements freely — this is a
moodboard/canvas item, not a list.

## Usage

```tsx
import { DragItem, DragItems } from "@/components/ui/drag-items";

<DragItems>
  <DragItem defaultPosition={{ x: 24, y: 24 }}>A</DragItem>
  <DragItem defaultPosition={{ x: 140, y: 80 }}>B</DragItem>
</DragItems>
```

## Props

### DragItem

| Prop | Type | Default |
|---|---|---|
| `defaultPosition` | `{ x: number; y: number }` | `{ x: 0, y: 0 }` |
| `bounded` | `boolean` | `true` (clamp within the parent `DragItems`) |
| `class` | `string` | — |

`DragItems` accepts `class`, `id`, and `children` only.
