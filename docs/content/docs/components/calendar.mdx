## Usage

```tsx
import { Calendar, CalendarState } from "@/components/ui/calendar";

@Component()
class BookingCalendar extends StatefulComponent {
  @State() calendarState = new CalendarState({
    onSelect: (date) => console.log(date),
  });

  render() {
    return <Calendar state={this.calendarState} />;
  }
}
```

## Props

### CalendarState

| Prop | Type | Default |
|---|---|---|
| `defaultMonth` | `Date` | today |
| `mode` | `"single" \| "range"` | `"single"` |
| `selected` | `Date` | — (controlled, `single` mode) |
| `selectedRange` | `{ from?: Date; to?: Date }` | — (controlled, `range` mode) |
| `onSelect` | `(date: Date) => void` | — (`single` mode) |
| `onSelectRange` | `(range: { from?: Date; to?: Date }) => void` | — (`range` mode) |
| `disabled` | `(date: Date) => boolean` | — |

### Calendar

| Prop | Type | Default |
|---|---|---|
| `state` | `CalendarState` | — required |

In `range` mode the first click sets `from`, the second sets `to`; clicking before `from`, or after a
completed range, starts a new range.

```tsx
@State() calendarState = new CalendarState({
  mode: "range",
  onSelectRange: ({ from, to }) => console.log(from, to),
});
```

For a Popover-triggered variant, see [Date Picker](/docs/components/date-picker).
