## About

Purely presentational — no Morphos equivalent. Distinct from `ChainOfThought` (a stepped list of
named steps): this is a single block, typically collapsed by default once `streaming` becomes
`false`. The trigger label shows "Thinking…" while `streaming`, then "Thought for Ns" once
`duration` is known.

## Usage

```tsx
import { Reasoning } from "@/components/ui/reasoning";

<Reasoning streaming={isStreaming} duration={elapsedSeconds}>
  The user is asking about refund windows...
</Reasoning>
```
