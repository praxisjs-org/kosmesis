## About

Purely presentational — no Morphos equivalent. Structurally close to `AiTask`/`Reasoning`
(collapsible header + detail body), styled monospace and meant to hold raw input/output JSON as
`children`.

## Usage

```tsx
import { AiToolCall } from "@/components/ui/ai-tool-call";

<AiToolCall name="search_docs" status="done">
  {JSON.stringify({ query: "refund policy" })}
</AiToolCall>
```
