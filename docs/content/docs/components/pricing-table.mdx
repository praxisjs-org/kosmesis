## About

Purely presentational — no Morphos equivalent. `PricingPlan`'s name/description are plain
children (a heading + paragraph) rather than dedicated slots, matching the public prop API of
`Card` — only `PricingPlanPrice` and `PricingPlanFeature` get dedicated components since their
formatting (price/period split, check-marked list item) is genuinely repetitive.

## Usage

```tsx
import { PricingPlan, PricingPlanFeature, PricingPlanPrice, PricingTable } from "@/components/ui/pricing-table";

<PricingTable>
  <PricingPlan highlighted>
    <h3>Pro</h3>
    <PricingPlanPrice price="$19" period="mo" />
    <ul>
      <PricingPlanFeature>Unlimited projects</PricingPlanFeature>
      <PricingPlanFeature>Priority support</PricingPlanFeature>
    </ul>
    <Button>Get started</Button>
  </PricingPlan>
</PricingTable>
```

## Props

### PricingPlan

| Prop | Type | Default |
|---|---|---|
| `highlighted` | `boolean` | `false` |
| `class` | `string` | — |

### PricingPlanPrice

| Prop | Type | Default |
|---|---|---|
| `price` | `string` | — |
| `period` | `string` | — |
| `class` | `string` | — |

`PricingTable`/`PricingPlanFeature` accept `class` and `children` only.
