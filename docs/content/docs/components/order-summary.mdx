## About

Purely presentational — no Morphos equivalent. `OrderSummaryTotal` is visually distinct (larger,
bolder, top border) from `OrderSummaryItem` — always place it last.

## Usage

```tsx
import { OrderSummary, OrderSummaryItem, OrderSummaryTotal } from "@/components/ui/order-summary";

<OrderSummary>
  <OrderSummaryItem label="Subtotal" value="$49.00" />
  <OrderSummaryItem label="Shipping" value="$4.99" />
  <OrderSummaryTotal value="$53.99" />
</OrderSummary>
```

## Props

### OrderSummaryItem

| Prop | Type | Default |
|---|---|---|
| `label` | `Children` | — |
| `value` | `Children` | — |

### OrderSummaryTotal

| Prop | Type | Default |
|---|---|---|
| `label` | `Children` | `"Total"` |
| `value` | `Children` | — |
| `class` | `string` | — |

`OrderSummary` accepts `class` and `children` only.
