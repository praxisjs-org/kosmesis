## About

Purely presentational — no Morphos equivalent. Composes `Message` (registry dependency) and adds
a trailing `actions` row aligned under the bubble (indented past the avatar), meant to host
`FeedbackBar`, a copy button, etc. — something plain `Message` doesn't provide.

## Usage

```tsx
import { AiMessage } from "@/components/ui/ai-message";
import { FeedbackBar } from "@/components/ui/feedback-bar";

<AiMessage from="assistant" avatar={<BotAvatar />} actions={<FeedbackBar />}>
  Refunds are available within 30 days of purchase.
</AiMessage>
```
