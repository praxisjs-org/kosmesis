## About

Purely presentational + an `IntersectionObserver` — no Morphos equivalent. The left column is a
plain scrolling list of sections; the right column stays `sticky` and shows whichever section is
currently centered in the viewport. Every panel is rendered once and toggled via a `data-active`
attribute (not swapped in/out), matching how the rest of the registry drives per-item reactive
state through data attributes rather than re-rendering children.

## Usage

```tsx
import { StickyScroll, type StickyScrollItem } from "@/components/ui/sticky-scroll";

const items: StickyScrollItem[] = [
  { id: "1", title: "Collect", description: "Gather data from every source in one pipeline." },
  { id: "2", title: "Transform", description: "Clean and reshape it with a declarative pipeline." },
];

<StickyScroll items={items} />
```

## Props

| Prop | Type | Default |
|---|---|---|
| `items` | `StickyScrollItem[]` | — |
| `class` | `string` | — |

`StickyScrollItem` is `{ id: string; title: string; description: string; content?: Children }` — `content` overrides what the sticky panel shows for that item (defaults to its `title`).
