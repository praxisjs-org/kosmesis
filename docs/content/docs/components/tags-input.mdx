## About

Purely presentational — no Morphos equivalent. `value` behaves like `CalendarState.selected`:
pass a plain array for uncontrolled use, or a getter function to stay controlled.

## Usage

```tsx
import { TagsInput } from "@/components/ui/tags-input";

<TagsInput defaultValue={["design", "frontend"]} onChange={(tags) => console.log(tags)} />
```

## Props

| Prop | Type | Default |
|---|---|---|
| `value` | `string[]` | — (uncontrolled when omitted) |
| `defaultValue` | `string[]` | `[]` |
| `max` | `number` | — (unlimited) |
| `disabled` | `boolean` | `false` |
| `placeholder` | `string` | `"Add tag..."` |
| `onChange` | `(tags: string[]) => void` | — |
| `class` | `string` | — |
