## Usage

```tsx
import { Button } from "@/components/ui/button";
import {
  Card,
  CardAction,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle,
} from "@/components/ui/card";

<Card class="w-96">
  <CardHeader>
    <CardTitle>Create project</CardTitle>
    <CardDescription>Deploy your new project in one click.</CardDescription>
    <CardAction>
      <Button variant="ghost" size="sm">⋯</Button>
    </CardAction>
  </CardHeader>
  <CardContent>
    <p>Project settings go here.</p>
  </CardContent>
  <CardFooter class="border-t">
    <Button class="w-full">Deploy</Button>
  </CardFooter>
</Card>
```

## Parts

`Card`, `CardHeader`, `CardTitle`, `CardDescription`, `CardAction`, `CardContent`, `CardFooter` —
all accept `class`, `id`, and `children`. `CardHeader` uses a grid layout so `CardAction`
(typically a menu button) sits in the top-right corner automatically when present.
