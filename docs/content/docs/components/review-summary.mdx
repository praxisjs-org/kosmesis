## About

Purely presentational — no Morphos equivalent. `breakdown` is 5 counts ordered 5★..1★ (index 0 =
5-star count); each bar is scaled relative to the largest count in the array. Omit `breakdown` to
show just the average/count.

## Usage

```tsx
import { ReviewSummary } from "@/components/ui/review-summary";

<ReviewSummary average={4.6} count={238} breakdown={[180, 40, 10, 5, 3]} />
```
