## Usage

```tsx
import { Combobox } from "@/components/ui/combobox";

<Combobox
  placeholder="Search frameworks..."
  options={[
    { value: "praxisjs", label: "PraxisJS" },
    { value: "react", label: "React" },
    { value: "vue", label: "Vue" },
  ]}
  onValueChange={(value) => console.log(value)}
/>
```

<Callout type="info">
  Need a full "type to jump anywhere" command palette (grouped items, a `⌘K` dialog trigger)? See
  [Command](/docs/components/command), which is built for that instead of Combobox's
  single-field-select use case.
</Callout>
