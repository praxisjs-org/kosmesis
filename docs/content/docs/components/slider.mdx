## Usage

```tsx
import { Slider } from "@/components/ui/slider";

<Slider defaultValue={50} max={100} step={1} class="w-64" />
```

## Props

Passes through to Morphos's `Slider`.

| Prop | Type | Default |
|---|---|---|
| `value` / `defaultValue` | `number` | — |
| `min` / `max` / `step` | `number` | — |
| `disabled` | `boolean` | — |
| `name` | `string` | — |
| `orientation` | `"horizontal" \| "vertical"` | — |
| `onValueChange` | `(value: number) => void` | — |
