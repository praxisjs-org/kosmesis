## Usage

```tsx
import { ScrollArea } from "@/components/ui/scroll-area";

<ScrollArea class="h-72 w-48 rounded-md border">
  <div class="p-4">
    {Array.from({ length: 50 }, (_, i) => (
      <p key={i} class="text-sm">Item {i + 1}</p>
    ))}
  </div>
</ScrollArea>
```

<Callout type="info">
  Unlike Dialog/Tabs/Accordion, `ScrollArea` doesn't need a second, separately-tracked instance —
  it composes Viewport/Scrollbar/Thumb internally and passes `this` to them directly, so
  `new ScrollArea()` is the only instance you ever need.
</Callout>

## Props

### ScrollArea

| Prop | Type | Default |
|---|---|---|
| `type` | `"auto" \| "always" \| "scroll" \| "hover" \| "hidden"` | — |

### ScrollBar

Rendered internally by `ScrollArea` (once per axis) — you only need this directly for advanced
custom layouts.

| Prop | Type | Default |
|---|---|---|
| `scrollArea` | `ScrollArea` | — required |
| `orientation` | `"vertical" \| "horizontal"` | `"vertical"` |
