## About

Purely presentational — no Morphos equivalent. Mount it unconditionally (e.g. alongside a
selectable list) and drive `open` off your own selection state for the enter/exit transition.
`ActionBarSeparator` reuses `Separator`.

## Usage

```tsx
import { ActionBar, ActionBarSeparator, ActionBarText } from "@/components/ui/action-bar";
import { Button } from "@/components/ui/button";

<ActionBar open={selectedIds.length > 0}>
  <ActionBarText>{selectedIds.length} selected</ActionBarText>
  <ActionBarSeparator />
  <Button size="sm" variant="ghost">Archive</Button>
  <Button size="sm" variant="destructive">Delete</Button>
</ActionBar>
```

## Props

| Prop | Type | Default |
|---|---|---|
| `open` | `boolean` | `true` |
| `class` | `string` | — |

`ActionBarText`/`ActionBarSeparator` accept `class` and (for `ActionBarText`) `children`.
