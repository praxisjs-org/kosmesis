## Usage

```tsx
import { Popover } from "@morphos/overlays";
import { CalendarState } from "@/components/ui/calendar";
import { DatePicker } from "@/components/ui/date-picker";

@Component()
class BookingForm extends StatefulComponent {
  @State() popover = new Popover();
  @State() calendar = new CalendarState({
    onSelect: () => { this.popover.closePopover(); },
  });

  render() {
    return <DatePicker popover={this.popover} calendar={this.calendar} />;
  }
}
```

This is a composition, not a new primitive — [Popover](/docs/components/popover) (Morphos) +
[Calendar](/docs/components/calendar) (built from scratch). The trigger shows the
chosen date in place of the placeholder. If you need a different trigger style, compose those two
components directly instead of using `DatePicker`.

For a range, create the calendar with `mode: "range"` and use `DateRangePicker` — same props, and the
trigger shows `from – to`. To pick a time as well, see
[Date Time Picker](/docs/components/date-time-picker).

## Props

| Prop | Type | Default |
|---|---|---|
| `popover` | `Popover` | — required, a Morphos `Popover` instance |
| `calendar` | `CalendarState` | — required |
| `placeholder` | `string` | `"Pick a date"` |
| `class` | `string` | — |
