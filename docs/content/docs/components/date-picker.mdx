## Usage

```tsx
import { Popover } from "@morphos/overlays";
import { CalendarState } from "@/components/ui/calendar";
import { DatePicker } from "@/components/ui/date-picker";

@Component()
class BookingForm extends StatefulComponent {
  @State() popover = new Popover();
  @State() calendar = new CalendarState({
    onSelect: () => { this.popover.closePopover(); },
  });

  render() {
    return <DatePicker popover={this.popover} calendar={this.calendar} />;
  }
}
```

This is a composition, not a new primitive — [Popover](/docs/components/popover) (Morphos) +
[Calendar](/docs/components/calendar) (built from scratch). If you need a different trigger
style or a range picker, compose those two components directly instead of using `DatePicker`.
