## Usage

```tsx
import { Button } from "@/components/ui/button";
import { Tooltip, TooltipContent, TooltipTrigger } from "@/components/ui/tooltip";

@Component()
class SaveButton extends StatefulComponent {
  @State() tooltip = new Tooltip();

  render() {
    return (
      <>
        <TooltipTrigger tooltip={this.tooltip}>
          <Button variant="outline">Save</Button>
        </TooltipTrigger>
        <TooltipContent tooltip={this.tooltip}>Save changes (⌘S)</TooltipContent>
      </>
    );
  }
}
```

`Tooltip` itself is never mounted via JSX — it's instantiated directly and passed to
`TooltipTrigger`/`TooltipContent`. Since `TooltipTrigger` renders a plain `<span>`, it's safe to
nest a `<Button>` inside it (unlike `PopoverTrigger`/`DialogTrigger`, which render their own
`<button>`).
