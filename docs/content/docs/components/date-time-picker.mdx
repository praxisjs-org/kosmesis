## Usage

```tsx
import { Popover } from "@morphos/overlays";
import { CalendarState } from "@/components/ui/calendar";
import { DateTimePicker } from "@/components/ui/date-time-picker";
import { TimePickerState } from "@/components/ui/time-picker";

@Component()
class EventForm extends StatefulComponent {
  @State() popover = new Popover();
  @State() calendar = new CalendarState();
  @State() time = new TimePickerState({ minuteStep: 5 });

  onBeforeMount() {
    this.popover.onBeforeMount();
    this.calendar.onBeforeMount();
    this.time.onBeforeMount();
  }

  render() {
    return <DateTimePicker popover={this.popover} calendar={this.calendar} time={this.time} />;
  }
}
```

For a range, create the calendar with `mode: "range"` and use `DateTimeRangePicker` with a
`startTime` and an `endTime` state. Unlike [Date Picker](/docs/components/date-picker), the popover
stays open after a selection, since both a date and a time need to be chosen.

## Props

### DateTimePicker

| Prop | Type | Default |
|---|---|---|
| `popover` | `Popover` | — required |
| `calendar` | `CalendarState` | — required |
| `time` | `TimePickerState` | — required |
| `placeholder` | `string` | `"Pick date and time"` |
| `class` | `string` | — |

### DateTimeRangePicker

| Prop | Type | Default |
|---|---|---|
| `popover` | `Popover` | — required |
| `calendar` | `CalendarState` | — required, `mode: "range"` |
| `startTime` | `TimePickerState` | — required |
| `endTime` | `TimePickerState` | — required |
| `placeholder` | `string` | `"Pick a date and time range"` |
| `class` | `string` | — |
