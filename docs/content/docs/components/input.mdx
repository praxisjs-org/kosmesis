## Usage

```tsx
import { Input } from "@/components/ui/input";

<Input type="email" placeholder="you@example.com" />
<Input disabled placeholder="Disabled" />
<Input invalid placeholder="Invalid" />
```

## Props

Passes through to Morphos's `Input` — `type`, `value`, `defaultValue`, `placeholder`, `disabled`,
`readonly`, `required`, `invalid`, `name`, `autoComplete`, `maxLength`, `minLength`, `onInput`,
`onChange`, `onFocus`, `onBlur`. See
[Morphos's Input docs](https://morphos.praxisjs.org/docs/inputs/input) for the full list.
