## Usage

These components are presentation for the file upload composables in
[`@praxisjs/composables`](https://praxisjs.org/docs/composables/upload) (installed automatically by the
CLI). The composable is attached with `@Compose` in **your** component, so validation options (`accept`,
`maxSize`, `maxFiles`, …) stay yours, and is passed to the Kosmesis component as a prop.

```tsx
import { FileUpload } from "@praxisjs/composables";
import { FileUploadList, FileUploadSummary } from "@/components/ui/file-upload-list";

@Component()
class Uploader extends StatefulComponent {
  @Compose(FileUpload, { url: "/api/upload", maxSize: 5 * 1024 * 1024, concurrency: 2 })
  upload!: FileUpload;

  render() {
    return (
      <>
        <FileUploadSummary upload={this.upload} />
        <FileUploadList upload={this.upload} />
      </>
    );
  }
}
```

Add files with `upload.add(files)` — for example from a [File Dropzone](/docs/components/file-dropzone)'s
`drop.files`. Each row shows the status and progress, with cancel while uploading, retry after a failure
or cancellation, and remove otherwise.

## Props

| Component | Prop | Type |
|---|---|---|
| `FileUploadList` | `upload` | `FileUpload` — required |
| `FileUploadSummary` | `upload` | `FileUpload` — required |
| both | `class` | `string` |
