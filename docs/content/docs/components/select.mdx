## Usage

```tsx
import { Select } from "@/components/ui/select";

<Select
  placeholder="Select a fruit"
  options={[
    { value: "apple", label: "Apple" },
    { value: "banana", label: "Banana" },
    { value: "cherry", label: "Cherry" },
  ]}
  onValueChange={(value) => console.log(value)}
/>
```

<Callout type="info">
  Morphos's `Select` takes a flat `options` array and renders its own trigger + listbox as one
  unit — there's no `SelectTrigger`/`SelectContent`/`SelectItem` compound API to compose (Radix
  has one; Morphos deliberately doesn't). Need children-based composition or free-text search
  instead? See [Combobox](/docs/components/combobox). Need a plain native picker?
  See [Native Select](/docs/components/native-select).
</Callout>

## Props

| Prop | Type |
|---|---|
| `options` | `{ value: string; label: string; disabled?: boolean }[]` |

| `disabled` / `required` / `clearable` | `boolean` |
| `name` | `string` |
| `onValueChange` | `(value: string) => void` |
| `onClear` | `() => void` |
