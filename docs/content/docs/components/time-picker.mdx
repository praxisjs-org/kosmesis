## Usage

```tsx
import { Popover } from "@morphos/overlays";
import { TimePicker, TimePickerState } from "@/components/ui/time-picker";

@Component()
class MeetingForm extends StatefulComponent {
  @State() popover = new Popover();
  @State() time = new TimePickerState({ hourCycle: 12, minuteStep: 5 });

  onBeforeMount() {
    this.popover.onBeforeMount();
    this.time.onBeforeMount();
  }

  render() {
    return <TimePicker popover={this.popover} time={this.time} />;
  }
}
```

The trigger shows the chosen value in place of the placeholder. Values are always `"HH:mm"` (or
`"HH:mm:ss"` with `showSeconds`) in 24-hour form, regardless of `hourCycle` — that only changes how
the picker displays and edits them.

For a range, use `TimeRangePicker` with two `TimePickerState` instances (`from` / `to`). To embed the
columns without a popover, render `TimePickerPanel` with a `TimePickerState` directly.

## Props

### TimePickerState

| Prop | Type | Default |
|---|---|---|
| `selected` | `string` | — (controlled) |
| `onSelect` | `(value: string) => void` | — |
| `hourCycle` | `12 \| 24` | `24` |
| `showSeconds` | `boolean` | `false` |
| `minuteStep` | `number` | `1` |

### TimePicker

| Prop | Type | Default |
|---|---|---|
| `popover` | `Popover` | — required |
| `time` | `TimePickerState` | — required |
| `placeholder` | `string` | `"Pick a time"` |
| `class` | `string` | — |

### TimeRangePicker

| Prop | Type | Default |
|---|---|---|
| `popover` | `Popover` | — required |
| `from` | `TimePickerState` | — required |
| `to` | `TimePickerState` | — required |
| `placeholder` | `string` | `"Pick a time range"` |
| `class` | `string` | — |
