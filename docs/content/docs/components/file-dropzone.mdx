## Usage

These components are presentation for the file upload composables in
[`@praxisjs/composables`](https://praxisjs.org/docs/composables/upload) (installed automatically by the
CLI). The composable is attached with `@Compose` in **your** component, so validation options (`accept`,
`maxSize`, `maxFiles`, …) stay yours, and is passed to the Kosmesis component as a prop.

```tsx
import { DropZone } from "@praxisjs/composables";
import { Compose, Ref, type Ref as RefType } from "@praxisjs/decorators";
import { FileDropzone } from "@/components/ui/file-dropzone";
import { FileErrors, FileList } from "@/components/ui/file-list";

@Component()
class Attachments extends StatefulComponent {
  @Ref<HTMLDivElement>() zoneRef!: RefType<HTMLDivElement>;

  @Compose(DropZone, "zoneRef", { accept: [".pdf", "image/*"], maxFiles: 5 })
  drop!: DropZone;

  render() {
    return (
      <>
        <FileDropzone drop={this.drop} zoneRef={this.zoneRef} description="PDF or images" />
        <FileErrors source={this.drop} />
        <FileList source={this.drop} />
      </>
    );
  }
}
```

`DropZone` attaches its drag listeners to the element it is given, so `zoneRef` must be the same
`@Ref()` you passed to `@Compose`. Clicking the zone (or pressing Enter / Space) opens the native
dialog; `data-dragging` is set while files are dragged over it.

## Props

| Prop | Type | Default |
|---|---|---|
| `drop` | `DropZone` | — required |
| `zoneRef` | `Ref<HTMLDivElement>` | — required |
| `title` | `string` | `"Drop files here or click to browse"` |
| `description` | `string` | — |
| `disabled` | `boolean` | — |
| `class` | `string` | — |
