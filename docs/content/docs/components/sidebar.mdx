## Usage

```tsx
import {
  Sidebar,
  SidebarContent,
  SidebarFooter,
  SidebarGroup,
  SidebarHeader,
  SidebarInset,
  SidebarMenu,
  SidebarMenuButton,
  SidebarMenuItem,
  SidebarProvider,
  SidebarState,
  SidebarTrigger,
} from "@/components/ui/sidebar";

@Component()
class AppShell extends StatefulComponent {
  @State() sidebar = new SidebarState();

  render() {
    return (
      <SidebarProvider sidebar={this.sidebar}>
        <Sidebar sidebar={this.sidebar}>
          <SidebarHeader>My App</SidebarHeader>
          <SidebarContent>
            <SidebarGroup>
              <SidebarMenu>
                <SidebarMenuItem>
                  <SidebarMenuButton as="a" href="/" isActive>Home</SidebarMenuButton>
                </SidebarMenuItem>
                <SidebarMenuItem>
                  <SidebarMenuButton as="a" href="/settings">Settings</SidebarMenuButton>
                </SidebarMenuItem>
              </SidebarMenu>
            </SidebarGroup>
          </SidebarContent>
          <SidebarFooter>v1.0.0</SidebarFooter>
        </Sidebar>
        <SidebarInset>
          <SidebarTrigger sidebar={this.sidebar} />
          <main>Page content</main>
        </SidebarInset>
      </SidebarProvider>
    );
  }
}
```

<Callout type="info">
  No Morphos primitive to wrap here — Radix doesn't have a sidebar primitive either, so
  shadcn/ui's own `Sidebar` is a composition of `Sheet` (mobile), buttons, and plain divs, and
  this mirrors that. `SidebarState` is a small custom state container (not a Morphos class) —
  it's fully self-contained, no dual-instantiation concerns.
</Callout>

## Notes

- `SidebarTrigger` checks a `(max-width: 767px)` media query at click time to decide whether to
  toggle the desktop rail or the mobile sheet.
- Theming uses dedicated `--sidebar`, `--sidebar-foreground`, `--sidebar-accent`, etc. CSS
  variables (already wired up by `kosmesis init`), separate from the page's `--background`, so a
  dark sidebar next to a light page (or vice versa) is just a token override away.

## Props

### SidebarState

Not mounted via JSX — instantiate once (`@State() sidebar = new SidebarState()`) and pass it to
every part below.

| Prop | Type | Default |
|---|---|---|
| `defaultOpen` | `boolean` | `true` |
| `onOpenChange` | `(open: boolean) => void` | — |

### SidebarProvider

| Prop | Type | Default |
|---|---|---|
| `sidebar` | `SidebarState` | — required |

### Sidebar

| Prop | Type | Default |
|---|---|---|
| `sidebar` | `SidebarState` | — required |
| `side` | `"left" \| "right"` | `"left"` |
| `collapsible` | `"offcanvas" \| "icon" \| "none"` | `"offcanvas"` |

### SidebarTrigger

| Prop | Type | Default |
|---|---|---|
| `sidebar` | `SidebarState` | — required |
| `children` | `Children` | `"☰"` |

### SidebarMenuButton

| Prop | Type | Default |
|---|---|---|
| `as` | `"button" \| "a"` | `"button"` |
| `href` | `string` | — only used when `as="a"` |
| `isActive` | `boolean` | — |
| `onClick` | `(event: MouseEvent) => void` | — |
| `variant` | `"default" \| "outline"` | `"default"` |
| `size` | `"default" \| "sm" \| "lg"` | `"default"` |

`SidebarInset`, `SidebarHeader`, `SidebarFooter`, `SidebarContent`, `SidebarGroup`,
`SidebarGroupLabel`, `SidebarGroupContent`, `SidebarMenu`, `SidebarMenuItem`, and
`SidebarSeparator` are layout-only — no props beyond `class`/`children`.
