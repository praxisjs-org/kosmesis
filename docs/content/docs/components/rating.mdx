## About

Purely presentational — no Morphos equivalent. `value` behaves like `CalendarState.selected`:
pass a plain number for uncontrolled use, or a getter function to stay controlled.

## Usage

```tsx
import { Rating } from "@/components/ui/rating";

<Rating defaultValue={3} max={5} onChange={(value) => console.log(value)} />
<Rating value={4} readOnly />
```

## Props

| Prop | Type | Default |
|---|---|---|
| `value` | `number` | — (uncontrolled when omitted) |
| `defaultValue` | `number` | `0` |
| `max` | `number` | `5` |
| `readOnly` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |
| `onChange` | `(value: number) => void` | — |
| `class` | `string` | — |
