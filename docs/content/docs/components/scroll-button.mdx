## About

Purely presentational — no Morphos equivalent. Same visibility convention as `ActionBar`: mount it
unconditionally and drive `visible` for the enter/exit transition (wrap the usage in a reactive
thunk in your own component if you want it to update without remounting). Pair with
`MessageScroller`'s `scrollToBottom()` for the `onClick`.

## Usage

```tsx
import { MessageScroller } from "@/components/ui/message-scroller";
import { ScrollButton } from "@/components/ui/scroll-button";

<div class="relative">
  <MessageScroller ref={scrollerRef}>...</MessageScroller>
  <ScrollButton visible={isScrolledUp} onClick={() => scrollerRef.current?.scrollToBottom()} />
</div>
```
