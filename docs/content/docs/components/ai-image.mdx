## About

Purely presentational — no Morphos equivalent. The `<img>` starts at `opacity-0` and fades in on
its native `load` event, so a slow/generated image doesn't pop in abruptly.

## Usage

```tsx
import { AiImage } from "@/components/ui/ai-image";

<AiImage src={generatedUrl} alt="Generated preview" caption="Generated with your prompt" />
```
