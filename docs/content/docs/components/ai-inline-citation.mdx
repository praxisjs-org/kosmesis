## About

Purely presentational — no Morphos equivalent. Renders as a link when `href` is given, otherwise a
plain span; `children` (if a string) becomes the native `title` tooltip shown on hover.

## Usage

```tsx
import { AiInlineCitation } from "@/components/ui/ai-inline-citation";

<p>
  Refunds are available within 30 days
  <AiInlineCitation index={1} href="https://example.com/refund-policy">Refund policy</AiInlineCitation>.
</p>
```

## Props

| Prop | Type | Default |
|---|---|---|
| `index` | `number` | — |
