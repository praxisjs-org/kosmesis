## Usage

```tsx
import { Popover } from "@morphos/overlays";
import { MonthPicker, MonthPickerState } from "@/components/ui/month-picker";

@Component()
class ReportFilter extends StatefulComponent {
  @State() popover = new Popover();
  @State() month = new MonthPickerState({
    onSelect: () => { this.popover.closePopover(); },
  });

  onBeforeMount() {
    this.popover.onBeforeMount();
    this.month.onBeforeMount();
  }

  render() {
    return <MonthPicker popover={this.popover} state={this.month} />;
  }
}
```

The trigger shows the chosen month in place of the placeholder. Values are `{ year, month }` with `month`
from 0 to 11.

For a range, create the state with `mode: "range"` and use `MonthRangePicker`: the first click sets
`from`, the second sets `to`, and a click before `from` (or after a completed range) starts a new range.
Ranges can span years.

Set `showYear: false` to hide the year navigation and drop the year from the displayed value — useful for
"month of the year" pickers. To embed the grid without a popover, render `MonthPickerPanel`.

## Props

### MonthPickerState

| Prop | Type | Default |
|---|---|---|
| `mode` | `"single" \| "range"` | `"single"` |
| `showYear` | `boolean` | `true` |
| `defaultYear` | `number` | current year |
| `selected` | `{ year: number; month: number }` | — (controlled, `single` mode) |
| `selectedRange` | `{ from?: MonthValue; to?: MonthValue }` | — (controlled, `range` mode) |
| `onSelect` | `(value: MonthValue) => void` | — |
| `onSelectRange` | `(range: MonthRange) => void` | — |
| `disabled` | `(value: MonthValue) => boolean` | — |

### MonthPicker / MonthRangePicker

| Prop | Type | Default |
|---|---|---|
| `popover` | `Popover` | — required |
| `state` | `MonthPickerState` | — required (`mode: "range"` for the range picker) |
| `placeholder` | `string` | `"Pick a month"` / `"Pick a month range"` |
| `class` | `string` | — |
