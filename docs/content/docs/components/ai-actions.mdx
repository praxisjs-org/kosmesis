## About

Purely presentational — no Morphos equivalent. `AiActions` is the row container; each `AiAction`
is a plain icon button (copy, regenerate, share, ...). Pairs well with `AiMessage`'s `actions` slot.

## Usage

```tsx
import { Icon } from "@morphos/icons";

import { AiAction, AiActions } from "@/components/ui/ai-actions";

<AiActions>
  <AiAction label="Copy" onClick={copyText}><Icon name="Copy" size={16} /></AiAction>
  <AiAction label="Regenerate" onClick={regenerate}><Icon name="RotateCw" size={16} /></AiAction>
</AiActions>
```
