## About

Purely presentational — no Morphos equivalent. `count` only affects the label when
`status="low-stock"` (renders "Only N left"); it's ignored for the other two statuses.

## Usage

```tsx
import { StockBadge } from "@/components/ui/stock-badge";

<StockBadge status="low-stock" count={3} />
```

## Props

| Prop | Type | Default |
|---|---|---|
| `status` | `"in-stock" \| "low-stock" \| "out-of-stock"` | — |
| `count` | `number` | — |
| `class` | `string` | — |
