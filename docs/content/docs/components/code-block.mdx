## About

Purely presentational — no Morphos equivalent, and deliberately avoids a heavy
syntax-highlighter dependency like shiki (same reasoning `Carousel` avoids Embla): plain
`<pre><code>` with a copy button, no highlighting.

## Usage

```tsx
import { CodeBlock } from "@/components/ui/code-block";

<CodeBlock code={source} language="ts" filename="greet.ts" />
```
