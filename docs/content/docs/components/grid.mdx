## About

Purely presentational — no Morphos equivalent. `cols`/`gap`/`colSpan`/`rowSpan` are runtime
numbers, so they drive `grid-template-columns`/`gap`/`grid-column`/`grid-row` via inline style
rather than `grid-cols-N`-style utility classes — a dynamically-built class string isn't visible
to Tailwind's build-time scanner.

## Usage

```tsx
import { Grid, GridItem } from "@/components/ui/grid";

<Grid cols={3} gap={4}>
  <GridItem colSpan={2}>Wide item</GridItem>
  <GridItem>Item</GridItem>
</Grid>
```

## Props

### Grid

| Prop | Type | Default |
|---|---|---|
| `cols` | `number` | `1` |
| `gap` | `number` | `4` (Tailwind spacing steps, i.e. `4` = `1rem`) |
| `class` | `string` | — |

### GridItem

| Prop | Type | Default |
|---|---|---|
| `colSpan` | `number` | — |
| `rowSpan` | `number` | — |
| `class` | `string` | — |
