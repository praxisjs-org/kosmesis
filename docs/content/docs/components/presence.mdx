## About

Purely presentational — no Morphos equivalent. Deliberately doesn't reuse `Avatar`: Morphos's
`Avatar` needs one instance per user (to track image load/error state), which doesn't compose
cleanly with a flat `users` array prop, so image/initials fallback is handled locally instead.
`PresenceDot` is a separate small status indicator meant to sit on an `Avatar`'s corner.

## Usage

```tsx
import { Presence, PresenceDot } from "@/components/ui/presence";

<Presence users={[{ id: "1", name: "Ada Lovelace" }, { id: "2", name: "Grace Hopper" }]} max={4} />
<PresenceDot status="online" class="absolute right-0 bottom-0" />
```

### PresenceDot

| Prop | Type | Default |
