## About

`Progress` wraps Morphos's `Progress` primitive directly since it only needs a `div` for its fill.
`ProgressCircle` needs an SVG ring nested inside the progressbar element, and Morphos's `Progress`
renders no children at all — so the same `value`/`min`/`max` percentage math is duplicated here
directly against a local `role="progressbar"` element instead.

## Usage

```tsx
import { ProgressCircle } from "@/components/ui/progress-circle";

<ProgressCircle value={65} showLabel />
<ProgressCircle /> {/* indeterminate — spins */}
```
