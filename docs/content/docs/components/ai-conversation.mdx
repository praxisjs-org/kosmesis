## About

Purely presentational — no Morphos equivalent. Distinct from the plain `MessageScroller` (which
has no built-in scroll button): `AiConversation` wires a `ScrollButton` (registry dependency) to
appear automatically once the user scrolls more than ~24px away from the bottom. It only owns
scroll behavior — wrap your message list in `MessageGroup` for spacing/padding.

## Usage

```tsx
import { AiConversation } from "@/components/ui/ai-conversation";
import { AiMessage } from "@/components/ui/ai-message";
import { MessageGroup } from "@/components/ui/message";

<AiConversation>
  <MessageGroup>
    {messages.map((m) => <AiMessage key={m.id} from={m.from}>{m.text}</AiMessage>)}
  </MessageGroup>
</AiConversation>
```

## Props

`AiConversation` accepts `class` and `children` only. Its instance also exposes
`scrollToBottom(behavior?: ScrollBehavior)`.
