## Usage

```tsx
import { Alert, AlertDescription, AlertTitle } from "@/components/ui/alert";

<Alert>
  <AlertTitle>Heads up!</AlertTitle>
  <AlertDescription>You can add components using the CLI.</AlertDescription>
</Alert>

<Alert variant="destructive">
  <AlertTitle>Error</AlertTitle>
  <AlertDescription>Your session has expired. Please log in again.</AlertDescription>
</Alert>
```

## Props

| Prop | Type | Default |
|---|---|---|
| `variant` | `"default" \| "destructive"` | `"default"` |
| `title` | `string` | — rendered as Morphos's title slot, above `children` |
| `live` | `"polite" \| "assertive"` | `"polite"` — sets `aria-live` |

`variant="destructive"` maps to Morphos's `variant="error"` under the hood; `variant="default"`
maps to Morphos's `"info"`. All other props (`class`, `id`, `children`, ...) pass through to
Morphos's `Alert` unchanged.
