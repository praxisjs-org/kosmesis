## Usage

```tsx
import { AspectRatio } from "@/components/ui/aspect-ratio";

<AspectRatio ratio={16 / 9} class="overflow-hidden rounded-md bg-muted">
  <img src="/photo.jpg" alt="" class="size-full object-cover" />
</AspectRatio>
```

## Props

| Prop | Type | Default |
|---|---|---|
| `ratio` | `number` | `1` |
