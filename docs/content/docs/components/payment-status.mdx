## About

Purely presentational — no Morphos equivalent. Unlike `Badge` (generic, no built-in semantics),
`PaymentStatus` hardcodes the four payment states and their colors/labels — pass the raw `status`
value and it renders correctly, no variant mapping needed on your end.

## Usage

```tsx
import { PaymentStatus } from "@/components/ui/payment-status";

<PaymentStatus status="succeeded" />
<PaymentStatus status="refunded" />
```

## Props

| Prop | Type | Default |
|---|---|---|
| `status` | `"succeeded" \| "processing" \| "failed" \| "refunded"` | — |
