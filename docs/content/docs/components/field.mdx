## Usage

```tsx
import { Field, FieldControl, FieldDescription, FieldError, FieldLabel } from "@/components/ui/field";
import { Input } from "@/components/ui/input";

@Component()
class SignupForm extends StatefulComponent {
  @Prop() invalid = false;
  @State() field = new Field({ invalid: this.invalid, required: true });

  render() {
    return (
      <Field invalid={this.invalid} required>
        <FieldLabel field={this.field}>Email</FieldLabel>
        <FieldControl field={this.field}>
          <Input id={this.field.fieldId} type="email" required invalid={this.invalid} />
        </FieldControl>
        <FieldDescription field={this.field}>We'll never share your email.</FieldDescription>
        <FieldError field={this.field}>Please enter a valid email address.</FieldError>
      </Field>
    );
  }
}
```

`FieldError` only renders while `field.invalid` is true. `Fieldset` (also exported from this
file) wraps a native `<fieldset>` with a `legend` string prop, for grouping several `Field`s.

## Props

### Field

Extends Morphos's `Field` — instantiate it in state (`@State() field = new Field({...})`) and
pass it to every part below via their `field` prop.

| Prop | Type | Default |
|---|---|---|
| `invalid` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |
| `required` | `boolean` | `false` |

### FieldLabel

| Prop | Type | Default |
|---|---|---|
| `field` | `Field` | — required |

### FieldDescription

| Prop | Type | Default |
|---|---|---|
| `field` | `Field` | — required |
| `id` | `string` | — |

### FieldError

| Prop | Type | Default |
|---|---|---|
| `field` | `Field` | — required |
| `id` | `string` | — |

### FieldControl

| Prop | Type | Default |
|---|---|---|
| `field` | `Field` | — required |

### Fieldset

| Prop | Type | Default |
|---|---|---|
| `disabled` | `boolean` | — |
| `legend` | `string` | — |
| `aria-label` | `string` | — |
| `aria-labelledby` | `string` | — |
| `aria-describedby` | `string` | — |
