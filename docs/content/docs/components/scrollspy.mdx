## About

Purely presentational + an `IntersectionObserver` — no Morphos equivalent. `ScrollspyState` is a
pure state container, the same pattern as `CalendarState`/`CarouselState`: never mounted via JSX,
so it never receives lifecycle callbacks on its own — forward `onMount`/`onUnmount` to it from
whatever component instantiates it.

## Usage

```tsx
import { Scrollspy, ScrollspyLink, ScrollspyState } from "@/components/ui/scrollspy";

@Component()
class Toc extends StatefulComponent {
  @State() spy = new ScrollspyState({ ids: ["intro", "features", "pricing"] });

  onMount() { this.spy.onMount(); }
  onUnmount() { this.spy.onUnmount(); }

  render() {
    return (
      <Scrollspy>
        <ScrollspyLink state={this.spy} target="intro">Intro</ScrollspyLink>
        <ScrollspyLink state={this.spy} target="features">Features</ScrollspyLink>
        <ScrollspyLink state={this.spy} target="pricing">Pricing</ScrollspyLink>
      </Scrollspy>
    );
  }
}
```

## Props

### ScrollspyState

| Prop | Type | Default |
|---|---|---|
| `ids` | `string[]` | `[]` |
| `offset` | `number` | `0` |

### ScrollspyLink

| Prop | Type | Default |
|---|---|---|
| `state` | `ScrollspyState` | — |
| `target` | `string` | — |
| `class` | `string` | — |
