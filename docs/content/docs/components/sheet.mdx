## Usage

```tsx
import { Sheet, SheetContent, SheetTrigger } from "@/components/ui/sheet";

@Component()
class Cart extends StatefulComponent {
  @State() sheet = new Sheet({ side: "right" });

  render() {
    return (
      <>
        <SheetTrigger drawer={this.sheet}>Open cart</SheetTrigger>
        <SheetContent drawer={this.sheet}>...</SheetContent>
      </>
    );
  }
}
```

<Callout type="info">
  shadcn/ui's `Sheet` and `Drawer` both wrap the same underlying Radix `Dialog`, differing only in
  which side they slide from. Kosmesis mirrors that: `Sheet` is `Drawer` re-exported under a
  different name — the props (including the part names like `drawer=`) are identical. See
  [Drawer](/docs/components/drawer) for the full API.
</Callout>
